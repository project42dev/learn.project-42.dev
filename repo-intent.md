# Repo intent — learn.project-42.dev

**Project 42 Learn — self-paced AI learning, assessments, progress, transcripts.**

## What this repo is

The dedicated learning experience at learn.project-42.dev: free, provider-neutral
AI learning paths, knowledge checks, progress, badges, and transcripts. Current
catalog: the twelve-module Reliable Agent Workflows path and the sixteen-module AI
Foundations path, with a practical capstone (calibration packages, required
operating artifacts, evidence mapping, a 100-point rubric, Reliable Agent Operator
badge). Profiles preserve attempts, capstone revisions, evidence links, badges, and
portable JSON/CSV exports in device-local storage.

## Shape

- Next.js app with Playwright test configs for app, production progress, and
  production registration flows separately
- `npm run governance:check`, `lint`, `test` — the verify pipeline

## How it relates to other repos

- Consumes the versioned open-source learning core from
  **`project42dev/project42-platform`**
