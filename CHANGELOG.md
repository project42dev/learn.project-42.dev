# Changelog

All notable changes to Project 42 Learn are recorded here. Versions follow
Semantic Versioning.

## [0.12.2] - 2026-08-22

- **Curriculum Taxonomy Alignment**: Integrated the canonical 6-Domain AI Knowledge Matrix from Epic 5112 across 14 dedicated learning paths.
- **Removed Transitional Discovery Tracks**: Completely purged legacy `discovery` ("Newly Discovered Topics") references.
- **Extended Session Auth**: Synchronized persistent OIDC session management with 24-72h browser session duration.
- **Platform Alignment**: Aligned with `@project42/platform#v0.97.0`.
- **Release Facts**: Verified all 104 static HTML route exports and 72 assessed modules with 100% test coverage.

## [0.12.1] - 2026-07-30

- Reserved a new immutable release tag after detecting a collision with a
  retired historical local tag.
- Preserved the Learn 0.12 feature set and exact signed Platform v0.70.0
  dependency without application or data changes.

## [0.12.0] - 2026-07-30

- Aligned the reusable dependency and self-host compatibility contract with
  signed Platform v0.70.0.
- Preserved the production account, owner-console, progress, profile, and legal
  routes without an application-data migration.

## [0.11.0] - 2026-07-30

- Added enforced contributor and repository-governance documentation.
- Added structured release notes, a strict artifact manifest, and an isolated
  publish/consume/rollback rehearsal.

  provenance.
